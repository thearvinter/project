 Анализ личных расходов

Веб-приложение на Streamlit. Загружаете банковскую выписку (CSV или Excel) и видите:
сколько потрачено, на что, как менялись траты по месяцам и какие покупки были необычно крупными.

**Дисциплина:** «Разработка программных средств»

## Что умеет

- читает выписку в CSV (разделитель `;` или `,`, кодировка UTF-8 или Windows-1251) и XLSX;
- сам раскладывает операции по категориям: продукты, кафе, транспорт и т.д.;
- показывает доходы, расходы, баланс и средний расход в день;
- рисует круговую диаграмму по категориям и график по месяцам;
- находит необычно крупные траты;
- фильтр по периоду, поиск по описанию, выгрузка в CSV.

## Как запустить

### Обычный способ

```bash
git clone https://github.com/thearvinter/project.git
cd project
python3 -m venv .venv
source .venv/bin/activate        # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется http://localhost:8501. Если файл не загружен, приложение показывает демо-выписку
`data/sample.csv` (вымышленные операции за май - октябрь 2026).

### Через Docker

```bash
docker build -t expense-app .
docker run -p 8501:8501 expense-app
```

## Формат выписки

Нужны три колонки. Названия могут быть такими:

| Что | Название колонки | Пример |
|---|---|---|
| Дата | `Дата` или `Дата операции` | `05.10.2026` |
| Описание | `Описание` или `Назначение платежа` | `Пятёрочка` |
| Сумма | `Сумма` или `Сумма операции` | `-1 234,56` |

Расход пишется с минусом, доход без знака.

## Как ищутся крупные траты

Алгоритм ищет необычные траты отдельно для каждой категории (Продукты, Транспорт, Кафе и т.д.). Это нужно потому, что покупка продуктов на 5 000 ₽ - норма, а поездка на такси за 5 000 ₽ - явная аномалия.

Логика поиска:

Для каждой категории считаются квартили Q1 (25%) и Q3 (75%). Они показывают, в каком диапазоне сосредоточена основная масса обычных трат.

Трата считается крупной, если она больше Q3 + 3 * (Q3 - Q1) и при этом не меньше 3 000 ₽.

Почему выбран именно такой подход:

Одна покупка не портит порог. В отличие от расчёта через среднее арифметическое, квартили не «ломаются» от одной огромной траты (например, покупки машины). Поэтому алгоритм продолжает находить обычные аномалии вроде нового ноутбука.

Мелкие траты не попадают в список. Коэффициент 3 (вместо стандартного 1,5) делает порог строже, чтобы не считать аномалией просто «дорогой кофе». А нижняя планка в 3 000 ₽ отсекает шум в категориях с изначально низким чеком (например, поездки на метро).

Работает для любой выписки. Порог не «зашит» в код намертво, а подстраивается под конкретные траты пользователя.

Пример: если в категории «Кафе» 75% трат дешевле 1 200 ₽, а 25% - дешевле 400 ₽, то порог составит 1200 + 3(1200-400) = 3 600 ₽. Значит, банкет на 10 000 ₽ будет найден, а обед за 1 500 ₽ - нет.
